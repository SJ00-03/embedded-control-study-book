# Create Next Lesson Prompt

`progress_state.yml`의 `next_lesson` 항목을 기준으로 새 lesson을 작성하세요.

## 작성 원칙

- 주요 본문은 한국어로 작성합니다.
- 독자는 전기/전자공학 배경의 임베디드 제어 SW 취업 준비생입니다.
- 실무 구현과 디버깅 관점을 포함합니다.
- 저작권 있는 교재 문장을 복제하지 말고 원본 설명과 예제를 작성합니다.
- Codex Web과 GitHub PR 기반 작업을 전제로 하며, 로컬 Windows 앱이나 특정 데스크톱 IDE를 가정하지 않습니다.

## 필수 구조

아래 12개 절을 정확히 포함하세요.

1. 학습 목표
2. 왜 이 개념이 임베디드 제어 SW에서 중요한가
3. 기초 개념
4. 공식 또는 이론의 유도/직관
5. 간단한 예시
6. 실무형 예시
7. 직접 구현 실습
8. 디버깅 포인트
9. 방산/로봇 SW 관점에서의 주의점
10. 확인 문제
11. 심화 과제
12. 포트폴리오 연결 아이디어

## 완료 조건

1. lesson 파일을 생성합니다.
2. `python3 scripts/check_lesson_quality.py <lesson-path>`를 실행합니다.
3. `progress_state.yml`의 다음 항목을 갱신합니다.
4. 변경사항을 커밋하고 PR 설명에 다음 진행 방향을 적습니다.
