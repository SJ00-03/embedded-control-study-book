# Review Lesson Prompt

지정된 lesson을 검토하고 필요한 수정을 제안하거나 직접 반영하세요.

## 검토 기준

- 12개 필수 절이 모두 있는가?
- 한국어 설명이 명확하고 실무 지향적인가?
- 초급자가 따라갈 수 있는 기초 설명과 중급자가 얻을 수 있는 구현 관점이 함께 있는가?
- 코드 예제가 Linux cloud 환경에서 실행 가능한가?
- STM32, ROS 2, MATLAB 관련 내용이 특정 데스크톱 환경을 과도하게 가정하지 않는가?
- 방산 언급이 신뢰성, 안전, 검증, 문서화 범위에 머무르는가?
- 저작권 있는 교재의 문장 구조나 예제를 복제하지 않았는가?

## 검사 명령

```bash
python3 scripts/check_lesson_quality.py <lesson-path>
```

## 결과물

- 문제점 목록
- 수정된 파일 목록
- 실행한 검사 명령
- 다음 개선 제안
