# Start Study Session Prompt

지정한 lesson을 기준으로 개인 학습 세션을 시작하세요.

## 입력

- 학습할 lesson 경로: `book/<track>/<lesson>.md`
- 작성할 내 답안 경로: `study_notes/<track>/<lesson>_my_answer.md`
- 연결된 lab 경로가 있으면 함께 지정합니다.

## 진행 방식

1. lesson의 학습 목표, 확인 문제, 심화 과제를 먼저 파악합니다.
2. 기존 `study_notes/` 파일이 있는지 확인합니다.
3. 내 답안 파일이 없으면 빈 템플릿 생성을 제안하되, 사용자가 요청하기 전에는 임의로 만들지 않습니다.
4. 사용자가 직접 답을 작성할 수 있도록 문제 목록과 실습 체크리스트만 정리합니다.
5. 정답, 해설, 모범 답안은 아직 제공하지 않습니다.
6. lab이 있으면 빌드와 실행 명령을 안내합니다.

## 출력 형식

- 오늘 읽을 lesson
- 풀 확인 문제 목록
- 수행할 심화 과제 목록
- 실행할 lab 명령
- 내 답안을 작성할 파일 위치
- Codex 리뷰를 요청할 때 사용할 다음 단계

## 주의 사항

- `study_notes/`는 학습자의 개인 답안 공간이므로 명시 요청 없이 덮어쓰지 않습니다.
- `book/`에는 정답이나 해설을 추가하지 않습니다.
- `feedback/`과 `solutions/`는 학습자의 답안이 존재한 뒤에만 생성합니다.
