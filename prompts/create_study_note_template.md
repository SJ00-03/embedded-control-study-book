# Create Study Note Template Prompt

지정한 lesson의 확인 문제와 심화 과제를 바탕으로 `study_notes/` 아래에 빈 답안 템플릿을 생성하세요.

## 입력

- 원본 lesson 경로: `book/<track>/<lesson>.md`
- 생성할 템플릿 경로: `study_notes/<track>/<lesson>_my_answer.md`

## 작성 규칙

- 교육 안내와 섹션명은 한국어로 작성합니다.
- 원본 lesson의 확인 문제와 심화 과제 문항을 제목으로만 옮깁니다.
- 각 문항 아래에는 다음 빈 항목을 둡니다.
  - 내 답
  - 헷갈린 점
  - 실습 기록
  - 실행 결과
  - 오답 정리
  - 다음 복습 내용
- full answer, 모범 답안, 해설, 채점 기준은 포함하지 않습니다.
- 기존 `study_notes/` 파일이 있으면 사용자가 명시적으로 요청하지 않는 한 덮어쓰지 않습니다.
- 원본 `book/` lesson 내용은 수정하지 않습니다.

## 완료 조건

1. 템플릿 파일을 생성합니다.
2. 확인 문제와 심화 과제가 빠짐없이 제목으로 들어갔는지 확인합니다.
3. 답안이나 해설이 들어가지 않았는지 확인합니다.
4. 변경한 파일 목록을 보고합니다.
